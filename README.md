# inexbot-doc

> 纳博特(Nabor)机器人控制系统的技术顾问文档索引。
> 文档站点：https://doc.inexbot.com（130篇文档）
> 开发者中心：https://ones.inexbot.com/wiki/external/org/8cdyvHV7

## 概述

本仓库包含纳博特机器人控制系统的完整文档索引，覆盖产品选型、配置调试、二次开发、工艺应用全流程。

控制器产品线覆盖 C1102/C1200/C1201/C2200 系列，支持 6轴协作、SCARA、四轴并联等多种构型。

## 文档格式

所有文档均可通过以下 URL 格式访问：

```
https://doc.inexbot.com/【文档完整名称】
```
