# inexbot-doc

## 文件说明

| 文件 | 格式 | 用途 |
|------|------|------|
| `inexbot-doc-hermes.md` | Hermes SKILL（含 YAML frontmatter） | Hermes Agent 直接加载 |
| `inexbot-doc-claude-code.md` | Claude Code 格式 | Claude Code 项目参考 |
| `inexbot-doc-openclaw.md` | OpenClaw 格式 | OpenClaw 平台使用 |
| `inexbot-doc-opencode.json` | OpenCode JSON 格式 | OpenCode 工具链 |
| `inexbot-doc-raw.md` | 纯 Markdown | 通用格式，任意阅读 |
| `hash-map-snapshot.json` | VitePress hash map | 站点变更检测基线 |
