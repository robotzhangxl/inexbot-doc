# inexbot-doc

纳博特（inexbot）机器人控制系统的技术顾问skill，涵盖产品选型、配置调试、二次开发、工艺应用全流程。文档索引基于 doc.inexbot.com（510篇文档，含349篇独立伺服报错页面，含25.01版本7篇新文档）。**每次回答问题后自动追加 Q&A 到下方缓存区。**

## 文档来源

本仓库定时同步自 [doc.inexbot.com](https://doc.inexbot.com) 纳博特科技知识库。

| 文件 | 格式 | 用途 |
